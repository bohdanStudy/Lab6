Завдання · Challenge 8. Debug the Layout

← Усі challenges

style.css містить навмисно закладені помилки. На вузькому viewport сторінка має horizontal scroll, обрізаний hero heading, картки виходять за межі контейнера, sidebar займає непропорційно багато місця.

  1. Відкрийте DevTools і визначте елемент, який створює overflow.
  2. Перевірте його Box Model, computed width, min-width, max-width та Grid/Flexbox overlay.
  3. Знайдіть CSS rule, яка створює проблему, і визначте першопричину.
  4. Внесіть мінімальну зміну та повторно перевірте layout.

Для кожної проблеми зафіксуйте:

Проблема Причина CSS-властивість Виправлення
Horizontal overflow Фіксовані ширини сторінки та main перевищують viewport. width, grid-template-columns Обмежити ширину сторінки через min(); використовувати гнучкі Grid-треки.
Heading overflow nowrap забороняє перенос довгого заголовка. white-space, font-size Дозволити природний перенос і обмежити розмір через clamp().
Card overflow Фіксована ширина карток разом із нерозривним Flex-рядом не адаптується до вузької колонки. width, display, grid-template-columns Прибрати фіксовану ширину; використати адаптивний Grid.
Sidebar sizing Колонка sidebar фіксована на 300px і забирає майже всю ширину viewport. grid-template-columns Зробити колонку пропорційною, а на вузькому екрані складати layout в один стовпець.

Важливо: overflow-x: hidden — не виправлення. Поясніть, чому виник overflow, а не приховуйте його.
